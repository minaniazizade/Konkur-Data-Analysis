# Konkur-Data-Analysis

📊 College Entrance Exam Admission Data Analysis & Visualization

This project focuses on analyzing college entrance exam admission data and discovering meaningful patterns and relationships within the dataset.

Using Python and various data analysis and visualization libraries, the data is cleaned, explored, and analyzed. Different charts and interactive visualizations are used to investigate relationships between rankings, admitted fields of study, universities, and other features.

The project also includes an interactive Streamlit dashboard for exploring and presenting the analysis in a user-friendly way.

---

🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Streamlit
- Jupyter Notebook

---

📌 Project Features

- Exploring the structure of the dataset
- Handling and analyzing missing values
- Descriptive statistical analysis
- Analysis of numerical features
- Data distribution visualization
- Correlation analysis between features
- Analyzing the relationship between national rank and regional rank
- Analyzing top admitted fields of study for:
  - Mathematics
  - Experimental Sciences
  - Humanities
- Showing the number and percentage of admissions by field
- Creating interactive 3D visualizations
- Interactive data exploration using Streamlit
- Web-based dashboard for presenting analysis results

---

📊 Data Analysis

The project includes several stages of data analysis, including:

Data Exploration

- Dataset structure
- Data types
- Missing values
- Descriptive statistics

Correlation Analysis

The relationships between numerical features are analyzed using correlation matrices and heatmaps.

Admission Analysis

Admission data is analyzed based on different fields of study, including Mathematics, Experimental Sciences, and Humanities.

Ranking Analysis

The relationship between national ranking and regional ranking is investigated to identify patterns in the admission data.

Interactive Visualization

Interactive visualizations are created using Plotly, including 3D charts for exploring relationships between multiple variables.

---

🖥️ Streamlit Dashboard

The project includes an interactive dashboard built with Streamlit, allowing users to explore the dataset and visualizations directly through a web interface.
